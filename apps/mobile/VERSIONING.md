# Version policy

- `expo.version` is the public App Store and Play Store version.
- `ios.buildNumber` and `android.versionCode` increase for every submitted native build.
- Pre-launch builds use `0.x.y`; the first public release becomes `1.0.0`.
- EAS production builds use remote build-number management after the project is linked to the Expo account.
- The bundle and package identifier is `com.winterarc.app` on both platforms.
