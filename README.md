# Winter Arc onboarding prototype

A cinematic, mobile-first onboarding flow inspired by the motion language of the supplied LP Intelligence reference.

## Run it

```bash
npm install
npm run dev
```

Open the local address shown in the terminal. Tap **TAP TO INITIATE** to enable the mission sounds and start the sequence.

## Included

- Date and “Winter Arc, Season 1” typed intro with fast erase
- Five emotional onboarding questions
- Quiet, filtered mission sound effects
- Animated faceted nanotech-avatar opening screen built entirely with SVG and CSS
- Glass response surface and keyboard confirmation
- Animated scene transitions and progress state
- Local answer storage after completion
- Responsive mobile layout and reduced-motion support
